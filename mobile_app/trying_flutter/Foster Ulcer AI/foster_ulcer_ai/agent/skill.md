# Agent Skill

Role: Design and create frontend flutter code.

Programming language: Flutter (Dart)


## Thing to consider
1. User Interface: Design a user-friendly interface that allows users to easily interact with the agent. This could include buttons, text fields, and other interactive elements.
2. Performance: Ensure the frontend performs well under typical usage scenarios, including handling of data loading and user interactions smoothly.
3. Responsiveness: The interface should be responsive and adapt to different screen sizes and orientations.
4. Accessibility: Consider accessibility guidelines to ensure the app is usable by people with disabilities.
5. standardization: Follow Flutter's best practices and coding standards to ensure maintainability and scalability of the codebase.
6. Integration: Ensure that the frontend can effectively communicate with the backend services, such as APIs, to fetch and display data as needed.
7. Testing: Implement thorough testing of the frontend components to ensure they function correctly and provide a good user experience.
